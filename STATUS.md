# Grade 11 Assessment Generator — Status

## What's Built

- **Full generation pipeline:** Claude API → SymPy verification → native Word Math objects (OMML) → .docx
- **Multi-topic support:** Users select 1+ topics, each becomes a separate QUESTION block with mark allocation
- **Cognitive distribution:** CAPS balanced mode (K20/R35/C30/PS15) with grid in final document
- **Mark control:** User specifies grand total, distributed proportionally across questions
- **Marking guide:** Real DBE tick notation (`✓ substitution`, `✓✓ both answers`), fidelity flags for mismatches
- **Error handling:** Clear user-facing messages, all 3 verification retries functional, API usage logging

## Findings from Cost Analysis (Updated for Hierarchical Design)

**Token Profile (Hierarchical, 5 questions per 50-mark paper):**
- System prompt: ~2,330 tokens (100% static, resent every call)
- Per-question input: ~290 tokens (archetype context + cognitive targets + mark split)
- Per-question output: ~550 tokens avg (flat + hierarchical mix; hierarchical alone ~700, flat ~400)
- Normal case: 5 calls, worst case: 15 calls (3 retries per question max)

**Cost Estimate (Updated Pricing, 2026-06-24):**

| Model | Input/Output | Per-Call | Normal (5×) | Worst (15×) |
|---|---|---|---|---|
| **Opus 5.5** | $4/$20/1M | $0.0215 | **$0.108** | **$0.323** |
| **Sonnet 5** | $2/$10/1M | $0.0107 | **$0.054** | **$0.161** |
| **Haiku 4.5** | $1/$5/1M | $0.0054 | **$0.027** | **$0.081** |

Hierarchical design cost is **comparable to or slightly cheaper than flat design** (fewer total calls, slightly higher output tokens per call). Prompt caching (deferred) would reduce further.

**Cost Recommendation:** MVP use Sonnet 5 (~$0.05–$0.16 per paper), escalate to Opus 5.5 for complex/problem-solving-heavy papers.
